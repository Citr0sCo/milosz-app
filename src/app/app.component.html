Hi. My name is Milosz and I am a Software Engineer and a Web Developer.

In high school, I was introduced to the concept of the Web and fell in love with it. Ever since, I have been enthusiastic about creating and managing websites. My passion is backend web programming, but I also enjoy creating HTML + CSS + JavaScript frontends.

Over the years I’ve worked on school and client projects, from focused frontend builds to extensive PHP backends using frameworks and CMS systems. In my free time I experiment, learn how websites work, and build things for practice.
